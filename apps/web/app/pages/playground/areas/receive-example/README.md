# Receive example

Open `/playground/receive-example`. The overview shows all six screens. Use Single to choose Native SegWit, Taproot or Stacks, inspect the QR and full fixture address, copy, go back, close and reopen.

Fixture addresses and purpose labels demonstrate the toolkit; this is not a product redesign or a connected wallet. The existing product has direct-copy shortcuts not included in this focused example.

Use `stress=long` for wrapping fixtures, `theme=light|dark` and `frame=popup|tab`. Clipboard success appears only after the native write resolves; rejection shows an error.
