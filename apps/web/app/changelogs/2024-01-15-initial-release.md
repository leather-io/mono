# Initial Release

We're excited to announce the initial release of Leather Wallet! This release includes:

## Features
- Secure Bitcoin and Stacks wallet functionality
- Multi-account support
- Transaction history and management
- Hardware wallet integration
- DeFi protocol integration

## Security
- End-to-end encryption
- Local key storage
- Multi-signature support

Welcome to the future of Bitcoin and Stacks management!
