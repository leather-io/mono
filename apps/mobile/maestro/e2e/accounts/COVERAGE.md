# Accounts and settings coverage

Extension specs under `apps/extension/tests/specs/{switch-account,onboarding,settings,security,network,store-migrations,update-available}`. Flows live in this folder; reusable steps are in `shared/`.

Keys are random in every flow, so no flow types a secret key. Flows that need the same key twice copy it with the app's own Copy button on View Secret Key and paste it with the restore screen's Paste button. Run those flows with `QUIET=1`.

## Notes for running

- `shared/start.yaml` and `shared/open-app.yaml` in this folder only call the common `shared/start.yaml` and `shared/open-app.yaml`.
- The rename flows press Enter before tapping Save, so the keyboard is closed when Save is tapped (accounts-3).
- Flows that copy a secret key: `multiwallet/restore-wallet.yaml`, `multiwallet/view-secret-key.yaml`, `multiwallet-integrity/restore-already-added.yaml`, `multiwallet-integrity/view-non-active-wallet-key.yaml`, `multiwallet-integrity/remove-wallet-purges-metadata.yaml`, `onboarding/sign-in.yaml`, `onboarding/native-segwit-address.yaml`, `onboarding/stacks-address.yaml`, `settings/copy-secret-key.yaml`. Run them with `QUIET=1` and clear the simulator clipboard afterwards (`xcrun simctl pbcopy <udid> </dev/null`).
- `settings/support-page.yaml` loads the live support site in the in-app browser; it asserts only the address bar host (`docs.leather.io`, where the Guides link redirects).
