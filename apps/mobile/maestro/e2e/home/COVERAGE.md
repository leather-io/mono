# Home coverage

Extension specs: token-details, tokens, all-balances, activity, home-tabs, manage-tokens, bns-names, trending-tokens, ledger. Paths below are relative to `apps/extension/tests/specs` and `apps/mobile/maestro/e2e/home`.

Several tests that share all of their setup run in one flow, so a flow path can appear on more than one row.

## Blocked flows

Blocked flows stay in the suite with the tag `blocked` or `blocked-android`. App behaviour that differs from the extension is tracked internally under these ids:

- **home-1:** blocks `token-details/overview-balances.yaml` and `token-details/btc-empty.yaml`, which expect the overview to show the token's amount and fiat value.
- **home-2:** affects `token-details/btc-action-buttons.yaml`, which still passes.
- **home-3:** blocks `token-details/direct-url.yaml` on Android (`blocked-android`).
